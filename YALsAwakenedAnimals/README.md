## Coverage

Legend
-	🔴 Not implemented
-	🟢 Implemented
-	🔵 Implemented with changes
-	🟣 Homebrew

Heritages
-	🔴 [Aquatic Animal](https://2e.aonprd.com/Heritages.aspx?ID=291)\
	DD doesn't support separate land/swim speeds
-	🔴 [Climbing Animal](https://2e.aonprd.com/Heritages.aspx?ID=288)\
	No climbing in DD!
-	🔵 [Flying Animal](https://2e.aonprd.com/Heritages.aspx?ID=289)\
	Changes flight progression to be more similar to the [Tengu mod](https://steamcommunity.com/sharedfiles/filedetails/?id=3398206093); grants Take Flight
-	🟢 [Running Animal](https://2e.aonprd.com/Heritages.aspx?ID=290)
-	🟢 [Water-dwelling Animal](https://2e.aonprd.com/Heritages.aspx?ID=291)

Level 1
-	🔵 [Awakened Animal Lore](https://2e.aonprd.com/Feats.aspx?ID=5297)\
	Awakened Animal Lore is unlikely to ever come up in DD so you get Natural Skill with flavoring
-	🟢 [Awakened Magic](https://2e.aonprd.com/Feats.aspx?ID=5298)
-	🔴 [Fascinated by Society](https://2e.aonprd.com/Feats.aspx?ID=5299)\
	Dubious Knowledge doesn't exist in DD
-	🔵 [Land Legs](https://2e.aonprd.com/Feats.aspx?ID=5300)\
	Instead increases the flying/dwelling animals' speed by 5ft
-	🔴 [Learn by Watching](https://2e.aonprd.com/Feats.aspx?ID=5301)\
	Follow the Expert doesn't exist in DD
-	🔵 [Natural Senses](https://2e.aonprd.com/Feats.aspx?ID=5302)\
	Vision / Scent / Echolocation
-	🔴 [Sea Legs](https://2e.aonprd.com/Feats.aspx?ID=5303)\
	Can't have a separate swim speed!
-	🔵 [Take Flight](https://2e.aonprd.com/Feats.aspx?ID=5304)\
	Can be taken by animals with versatile heritages; provides a Leap-like action that allows to hop over enemies.
-	🟢 [Tooth and Claw](https://2e.aonprd.com/Feats.aspx?ID=5305)
-	🔴 [You're So Cute!](https://2e.aonprd.com/Feats.aspx?ID=5306)\
	Impressive Performance doesn't exist in DD

Level 5
-	🔵 [Fierce Grasp](https://2e.aonprd.com/Feats.aspx?ID=5307)\
	Can be taken by all animals since we don't have Climbing Animal
-	🟢 [Late Awakener](https://2e.aonprd.com/Feats.aspx?ID=5308)
-	🟢 [Natural Ambassador](https://2e.aonprd.com/Feats.aspx?ID=5309)
-	🔵 [Scurry!](https://2e.aonprd.com/Feats.aspx?ID=5310)\
	Honor system - can be taken by all animals as there's no Tiny size in DD
-	🔵 [Strong of Wing](https://2e.aonprd.com/Feats.aspx?ID=5311)
-	🔴 [Urban Jungle](https://2e.aonprd.com/Feats.aspx?ID=5312)\
	Track doesn't exist in DD
-	🟢 [Wild Stride](https://2e.aonprd.com/Feats.aspx?ID=5313)
-	🟣 Pack Tactics\
	Like Hobgoblins' Squad Tactics, but for animals

Level 9
-	🟢 [Animal Summoner](https://2e.aonprd.com/Feats.aspx?ID=5314)
-	🔵 [Full Flight](https://2e.aonprd.com/Feats.aspx?ID=5315)
