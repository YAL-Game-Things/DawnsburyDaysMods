# YAL's Misc Ancestry Feats

This mod adapts a few interesting ancestry feats as Universal Ancestry Feats:

- [Practiced Brawn](https://2e.aonprd.com/Feats.aspx?ID=5324) (lv1 Centaur feat)
- [Fierce Grasp](https://2e.aonprd.com/Feats.aspx?ID=5307) (lv5 Awakened Animal feat)
