# Flip (for martials)

This mod adds Flip (aka [Farabellus Flip](https://2e.aonprd.com/Feats.aspx?ID=2275)),
a Nimble Dodge/Flashy Dodge-like reaction for semi-dexterous martials.

I am taking the liberty of including Magus in the list of supported classes
as the class did not yet exist when this feat was printed,
though the writer's vision for remains a mystery -
e.g. you could build mobile and/or DEX-based champions even back then,
but the feat does not support the class.
