# Retrain Anytime

![](./media/screenshot-mini.png)

Enables access to Retraining and Shop at any point - in case you want to play around with build ideas mid-campaign or only realize that you forgot something after you've left Dawnsbury.

A pair for [Two-Week Return Policy](https://steamcommunity.com/sharedfiles/filedetails/?id=3703161657) in a way.
